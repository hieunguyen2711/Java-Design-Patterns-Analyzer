### FILE: AppointmentSlot.java
```java
public class AppointmentSlot {
    private String date;
    private String time;
    private Doctor doctor;
    
    public AppointmentSlot(String date, String time, Doctor doctor) {
        this.date = date;
        this.time = time;
        this.doctor = doctor;
    }
    
    public String getDate() {
        return date;
    }
    
    public String getTime() {
        return time;
    }
    
    public Doctor getDoctor() {
        return doctor;
    }
}
```

    public void checkInPatient(Patient patient, AppointmentSlot slot) {
        System.out.println("Checking in " + patient.getName() + 
                          " for appointment with Dr. " + slot.getDoctor().getName());
    }
}
